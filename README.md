# The World Today — 18 November 2026

A single-image summary of 18 November 2026's world news, laid out as a
one-page newspaper front page: **"THE WORLD TODAY — Wednesday 18 November
2026"**. Six stories and a news ticker cover the day's biggest headlines,
set in a clean broadsheet design that reads at a glance.

The image is a fixed 1024×1024 PNG (`entry.png`, 120,156 bytes). It is
produced by a generator script and shipped with the entry; `main.ts`
publishes it to the output directory make.fun expects.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png`. Without
`MAKEFUN_OUTPUT_DIR` set, the image is written to `/output/entry.png`.

## Files

- `entry.png` — the newspaper front page (1024×1024)
- `main.ts` — publishes `entry.png` to `$MAKEFUN_OUTPUT_DIR`
- `LICENSE` — MIT
